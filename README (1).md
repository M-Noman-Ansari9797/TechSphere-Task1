# Muhammad Noman — Portfolio

A simple, responsive personal portfolio website built with **HTML5** and **CSS3**, created as Task 1 for my Web Development Internship at **TechSphere**.

## 📖 About

This is a single-page portfolio site introducing me as a Computer Science student and aspiring software developer. It highlights my background, technical skills, and ways to get in touch.

## ✨ Features

- Clean, minimal single-page layout
- Sticky header with smooth in-page navigation (About, Skills, Contact)
- Responsive design that adapts to mobile screens
- Flexbox-based skills grid
- Custom Google Fonts (Space Grotesk & Inter)
- Semantic HTML structure with clearly commented sections

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, CSS custom properties/variables, media queries)
- [Google Fonts](https://fonts.google.com/)

## 📂 Project Structure

```
├── index.html      # Main HTML file
├── style.css       # Stylesheet
└── README.md       # Project documentation
```

## 📑 Sections

1. **Header** – Name and title
2. **About** – Brief introduction and background
3. **Skills** – Grid of technical skills (C++, Python, PHP, HTML & CSS, MySQL, Data Analysis, Data Structures, Git & GitHub)
4. **Contact** – Email and LinkedIn links

## 🚀 Getting Started

To view this project locally:

1. Clone the repository
   ```bash
   git clone https://github.com/M-Noman-Ansari9797/TechSphere-Task1
   ```
2. Open `index.html` in your browser

No build tools or dependencies required — it's pure HTML & CSS.
